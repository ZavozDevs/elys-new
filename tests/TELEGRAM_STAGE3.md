# Этап 3: ручная приёмка в Telegram

**Статус: полная приёмка не выполнена.** На сервере проверены авторизация в Web App
BotFather, поиск существующих форума и бота, чтение токена, запись inline-настроек и подхват тем;
создание бота через Web App отказывает на сервере (`createBot` → «Error»), не проверено. Локальные тесты не подтверждают
поведение серверов Telegram и BotFather или внешний вид сообщений. Не использовать основной аккаунт для первого
прогона. Создание и удаление групп/ботов — реальные действия, выполнять только с
согласия владельца тестового аккаунта. Не публиковать токены, сессии и содержимое data/.

## Запуск и восстановление

- [ ] Запустить Elys на тестовом аккаунте с чистым каталогом данных. Убедиться, что
  Web App BotFather создал обычного бота и включил inline-режим, без команд в диалоге,
  бота-управляющего и ручной правки файлов.
- [ ] Прервать настройку после создания бота, но до получения токена/включения inline.
  Перезапустить: используется уже созданный бот, дубликат не появляется.
- [ ] Заблокировать HTTPS-доступ к Web App BotFather при незавершённой настройке:
  понятная ошибка без токена/данных авторизации; перехода на команды нет.
- [ ] Проверить удаление `/start` и ответа у обоих участников. Сам диалог остаётся.
- [ ] Проверить форум: только владелец и бот, бот имеет права управления темами.
  Есть «Начало», «Ошибки», «Обновления», «Копии», пояснения закреплены.
- [ ] Перезапустить: нет второго бота, второго форума, дублированных тем и приветствия.
- [ ] На тестовом форуме удалить одну тему, перезапустить: восстановлена только она.
- [ ] Удалить тестовый форум, перезапустить: создан новый, приветствие и ссылки ведут в него.
- [ ] Выгнать бота из тестового форума, перезапустить: бот вернулся в тот же форум, второго форума нет.
- [ ] Стереть `core/forum` и данные бота из KV, перезапустить: найдены прежние форум и бот, ничего не создано.
- [ ] При недоступном форуме вызвать тестовую ошибку: важное приходит в личку.
  Заблокировать бота перед повтором: Elys снимает блокировку, повторяет удаляемую
  проверку `/start` и пытается доставить сообщение ещё раз.
- [ ] Написать боту с другого аккаунта: ответа нет. Нажать чужую кнопку настройки:
  изменение не применяется.
- [ ] Проверить Ctrl+C и повторный старт: нет блокировок сессий и потерянных настроек.

## Настройки и интерфейс

- [ ] `.config`: разделы «Настройки Elys», «Настройки модулей», «Назад», «Закрыть».
- [ ] Изменить начало команды на `! .`: работают оба, подсказки используют `!`.
  Добавить `п ping`, проверить `!п`, затем удалить сокращение.
- [ ] Переключить язык и картинки, перезапустить и проверить сохранение.
- [ ] Изменить настройки `Ping` и тестового модуля с числами, строками, списком,
  переключателем, выбором варианта, секретом. Неверный ввод не меняет значение.
- [ ] Ответить на конкретную подсказку в форуме. Проверить отмену кнопкой, `/cancel`
  и тайм-аут 3 минуты. Секрет скрыт в меню и сообщение с ним удалено.
- [ ] Добавить третьего участника в тестовый форум: ввод настроек запрещён. Удалить
  участника перед продолжением; не вводить настоящие секреты в этом сценарии.
- [ ] Открыть несколько меню, нажимать кнопки старого экрана, выгрузить тестовый модуль:
  нет выполнения устаревших действий и оставшихся фоновых задач.
- [ ] `.dlm examples/menu.py --trust`: `.menu`, `.pages`, `.photos <ссылка1> <ссылка2>`.
  Кнопки изменяют то же сообщение, список и галерея листаются, галерея закрывается.
- [ ] Проверить настройки и меню в личке, обычной группе и теме форума.
- [ ] Две ошибки подряд: доставка пачкой без звука в «Ошибки», общий номер совпадает
  с файлом лога; длинный трейсбек разбивается на сообщения без потери текста.

## Премиум и оформление — отдельная непроверенная гипотеза

- [x] (форма, список, галерея — проверено на живом аккаунте с Premium; `.config` как команда — не проверено) Без Premium — обычные эмодзи. С Premium — премиум-эмодзи в тексте `.menu`
  и `.config`, в том числе сразу после отправки, а не только после нажатия кнопки.
- [ ] Стили кнопок видны. В меню форума (сообщение бота) на кнопках премиум-иконки, в inline-формах перед текстом обычный эмодзи.
  Иконки со стилем проверяются отдельно только в личном сообщении бота владельцу.
- [ ] Баннер над формой показывается только при заданной ссылке и включённых картинках.
- [ ] Если премиум-эмодзи исчезают при первой отправке, записать версии клиентов,
  параметры и воспроизведение. Сравнить с отправкой заглушки и редактированием через
  0.3 секунды. Только после подтверждения добавлять обходной механизм: сейчас его нет.

Записать фактические результаты и ограничения. Не отмечать приёмку завершённой
на основании только pytest или снимка параметров API.
